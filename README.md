# ✨ Estética

> Projeto desenvolvido para uma experiência digital voltada ao universo da estética e beleza.

---

## 📖 Sobre o projeto

O **Estética** é um projeto desenvolvido como parte da minha jornada de aprendizado em desenvolvimento de software e criação de interfaces web.

A proposta é construir uma experiência visual agradável, organizada e intuitiva, utilizando recursos de **HTML, imagens, áudio e vídeo**.

Este projeto também serve como espaço para colocar em prática conceitos de desenvolvimento web, organização de arquivos, estruturação de páginas e criação de uma interface mais atrativa para o usuário.

---

## 🎯 Objetivos

* Desenvolver uma interface agradável e intuitiva;
* Praticar desenvolvimento web;
* Trabalhar com diferentes tipos de mídia;
* Aprender a organizar melhor um projeto;
* Aplicar conceitos de estruturação e apresentação de conteúdo;
* Evoluir o projeto conforme novos conhecimentos são adquiridos.
